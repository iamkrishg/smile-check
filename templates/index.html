For grown-ups and judges: how this works
  1. The photo is rotated, shrunk to 1024 px and re-saved, which removes location data. It is never stored.
  2. The photo is sent to an Azure OpenAI GPT-4o vision model with instructions to describe what it sees in kid-friendly words, never diagnose, and return structured data.
  3. Python checks the answer is safe and well-formed. If a possible cavity is found, the result always recommends a dentist.
  4. This page turns the data into stars, pins, a tooth map and missions. "Read it to me" uses the browser's built-in voice.

Limits: a phone photo can't show the spaces between teeth or what an X-ray reveals, and a clean result does not prove teeth are healthy. Real tools such as AICaries were tested in research studies; this demo is not.

Smile Check is a student science demo, not a medical device. Always see a dentist for a real check-up.
